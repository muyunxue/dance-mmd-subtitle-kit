# Fonts

The kit uses open-source Google Fonts (download with `download_fonts.ps1`) plus two Windows system fonts.

| Font | Use | License |
|---|---|---|
| Anton | S2/S5 display type | SIL OFL 1.1 |
| Archivo Black | S4 display type | SIL OFL 1.1 |
| Bebas Neue | S4 condensed subtitles | SIL OFL 1.1 |
| Permanent Marker | S6 handwriting | Apache 2.0 |
| Silkscreen | tiny monospace captions | SIL OFL 1.1 |
| Bungee / Monoton / Rubik Glitch / Pirata One / UnifrakturCook | experimental styles | SIL OFL 1.1 |
| Georgia / Georgia Italic | S4 serif lines | Windows system font (not redistributable) |
| Microsoft YaHei / Bold | Chinese/Japanese lines | Windows system font (not redistributable) |

Downloaded TTFs are ignored by git; run the script after cloning.
