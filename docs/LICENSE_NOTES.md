## 使用他人素材的建议

1. 只使用公开配布的模型/场景/动作；
2. 保留配布表与作者链接；
3. 禁止二次配布 / 商用（除非配布规约允许）；
4. 歌曲使用遵守平台版权规则（B站/YouTube 的音频识别与授权）。
